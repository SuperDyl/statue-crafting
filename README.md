# Statue Crafting

Adds a recipe to craft copper golem statues.
Currently, it takes 7 hours for a copper golem statue to fully oxidize
into a statue.

This allows you to craft copper golems from pumpkins and any oxidation level of block.

## Recipes

Place a carved pumpkin
and any copper block
to get 2 copper golem statues
of the same oxidation as the copper block
and waxed if the block was waxed.
